# Ashadeep Learning Compass

Build a complete, responsive, mobile-first multi-page website for "Ashadeep Computer Institute" (ACI), a computer training institute in Bhandup West, Mumbai. Tagline: "Learn Today. Build Your Future." Recreate the design exactly as described below.

DESIGN SYSTEM
- Colors: Deep navy (#0B1F4B) for hero/footer/dark sections, vibrant green (#16A34A, bright accent #22C55E) for buttons, highlights and icons, white page background, very light green tint (#ECFDF3) for info cards, soft pastel tints (pink, orange, blue, green) for course cards.
- Fonts: Poppins or Inter. Bold, large headings; key words in headings colored green (e.g. "Build Your Future.").
- Style: modern, clean, rounded corners (12–16px), soft shadows, generous spacing. Green icons in circles. Buttons are fully rounded with a right arrow icon.
- Layout: mobile-first (design at 390px width), then scale to tablet and desktop with multi-column grids.

GLOBAL HEADER (all pages)
- Sticky white header: circular ACI logo on the left with text "ASHADEEP" (navy, bold) and "COMPUTER INSTITUTE" (green), small tagline under it. Hamburger menu on the right (full nav on desktop).
- Menu: Home, About Us, Courses, MKCL, Gallery, Testimonials, Contact.
